# 执行进度、操作确认与引用

聊天页订阅 execution 事件，显示检索、模型、工具和工作流节点进度。最终回答沿用 completed 事件。
HIGH 风险操作显示服务端冻结参数卡片；确认接口只提交确认 ID，前端不能替换实际参数。
刷新后从后端恢复待确认卡片。当前标签页的 sessionStorage 保留原消息与 Idempotency-Key，用于确认后继续。
UNKNOWN 或 EXECUTING 状态要求核对外部系统，不能通过重复点击重放。

回答中的 `[来源:数字]` 被解析为来源按钮，其他内容按纯文本转义。来源面板读取当前租户可见的 READY 文档，
显示命中段落、邻近段落、章节、页码和字符区间。旧文档的定位字段可能为空，重新导入后可补齐。

工作流测试历史提供节点详情与从检查点恢复入口。恢复调用 execution ID 对应的服务端快照，不提交新画布和输入。
改变画布不会改变已经保存的测试运行快照。等待确认的测试运行可以先确认操作，再点击恢复。

验证：`npm run lint`、`npm test`、`npm run build`。
